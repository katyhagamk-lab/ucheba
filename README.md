Сайт: https://katyhagamk-lab.github.io/ucheba/

## Как связаны страницы

- Все сайты лежат на одном адресе `katyhagamk-lab.github.io`, поэтому у них общее хранилище браузера.
- Каждая платформа при открытии и после каждого ответа записывает короткий итог в `localStorage` под ключом `ucheba:sum:<id>`: `{ pct, stat, next, exam, at }`.
- Общая страница только читает эти итоги: процент готовности, следующий шаг, дни до экзамена. Ответы она не меняет.
- Дату экзамена можно поменять прямо на карточке, она хранится в `ucheba-hub-v1`.
- В шапке каждой платформы есть кнопка «Все предметы», она ведёт обратно сюда.

## Как добавить предмет

1. Собрать платформу предмета отдельным репозиторием на GitHub Pages.
2. В её коде записывать итог в `localStorage.setItem('ucheba:sum:<id>', ...)` и добавить ссылку `../ucheba/`.
3. В `index.html` в массиве `SUBJECTS` поставить `ready: true`, `url`, `store`, `theme`.

Сборка не нужна: один файл `index.html` и шрифты в `fonts/`.
